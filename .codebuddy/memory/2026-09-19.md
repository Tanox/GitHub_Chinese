### 经验（跨项目可复用）
- 用户脚本/单文件打包项目**永远不要手工维护模块清单**——用「从入口递归解析依赖图 + 拓扑排序」，
  并加「跨模块顶层重名冲突检测」，否则静默漏打包会产生运行期 ReferenceError 而构建却"成功"。
- 判断打包产物是否完整，可用 `@babel/core` parse + `path.scope.globals` 取未解析标识符，
  与浏览器/GM API 白名单比对——比人肉检查可靠，已固化为 `npm run validate`。
- 大 CSS（1165 行）拆分可用「按分节切分 + 保留原文件名做 `@import` 聚合入口」的方式，
  HTML 侧零改动，且可用脚本比对确保无规则丢失。
