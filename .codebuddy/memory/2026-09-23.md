### T2 · CSP（v1.9.36，提交 `f011eae`）
- `src/proxy.ts` 注入**基于 nonce** 的 CSP：`default-src 'self'`、`script-src 'self' 'nonce-…' 'strict-dynamic'`、
  `style-src 'self' 'unsafe-inline'`（自包含 CSS 必需）、`img-src 'self' data: blob:`、`font-src 'self' data:`、
  `connect-src 'self'`、`object-src 'none'`、`base-uri 'self'`、`form-action 'self'`、`frame-ancestors 'none'`、
  `upgrade-insecure-requests`。
- **关键**：CSP 同时写入**请求头** + 响应头——Next 依据请求头中的 nonce 为自身脚本注入 `nonce`。
- nonce 用 `btoa(crypto.randomUUID())`（edge 友好，不依赖 `Buffer`）。
- ⚠️ 无浏览器环境，未实测「无 CSP 违规」，仅验证 lint / tsc / `next build` 通过。
