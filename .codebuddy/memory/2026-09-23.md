### T1 · SSRF 加固（v1.9.35，提交 `0dd9cd0`）
- 新增 `src/lib/url-guard.js` 纯函数 `guardUrl()`：仅放行 `http(s)`；拦截 `localhost`/`.localhost`/`metadata*`、
  私网 IPv4（`10/8`、`172.16/12`、`192.168/16`、`127/8`、`0/8`、`169.254/16`、`100.64/10`）、
  IPv6（`::1`、`fc00::/7`、`fe80::/10`）。网段用**正则**表达以避免 `no-magic-numbers` 告警。
- `CollectErrorCode` 新增 `INVALID_URL: 3002`；`collector-core.js` 在 `page.goto` 前逐项校验，
  非法项**跳过**并经 SSE 透传错误码（不中断整批）。
- 新增 `tests/url-guard.test.mjs`（4 组）；单测 8 → 12 用例。
- 已知限制（文件头注明）：不做 DNS 解析 → 无法防 DNS rebinding；不归一化十六进制/十进制 IP 字面量。

### T2 · CSP（v1.9.36，提交 `f011eae`）
- `src/proxy.ts` 注入**基于 nonce** 的 CSP：`default-src 'self'`、`script-src 'self' 'nonce-…' 'strict-dynamic'`、
  `style-src 'self' 'unsafe-inline'`（自包含 CSS 必需）、`img-src 'self' data: blob:`、`font-src 'self' data:`、
  `connect-src 'self'`、`object-src 'none'`、`base-uri 'self'`、`form-action 'self'`、`frame-ancestors 'none'`、
  `upgrade-insecure-requests`。
- **关键**：CSP 同时写入**请求头** + 响应头——Next 依据请求头中的 nonce 为自身脚本注入 `nonce`。
- nonce 用 `btoa(crypto.randomUUID())`（edge 友好，不依赖 `Buffer`）。
- ⚠️ 无浏览器环境，未实测「无 CSP 违规」，仅验证 lint / tsc / `next build` 通过。
