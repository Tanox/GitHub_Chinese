组件库规范 · Wireframes

本规范定义 GitHub 中文采集工具前端的统一组件集合：基础组件、复合组件、业务组件与组件使用规则。 所有组件均基于同一套设计令牌（色彩 / 排版 / 间距 / 圆角 / 阴影 / 动效），并保证暗色主题下对比度满足 WCAG AA。

基础组件 · 按钮 Button

.btn / .btn-primary / .btn-danger / .btn-ghost / .btn-sm / .btn-lg

按钮用于触发动作。主操作使用 .btn-primary，危险操作用 .btn-danger，次级操作用 .btn-ghost。禁用态通过 disabled 或 aria-disabled 表达。

变体与尺寸

语义：primary / default / danger / ghost

规则：单页主操作不超过 1 个；按钮文案用动词短语；图标按钮必须带 aria-label。

业务组件 · 探针脚本 Probe

.probe / .probe-bar / .probe pre

注入式文本提取

probe.user.js · 控制台执行 
const nodes = [];
const walk = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
while (walk.nextNode()) {
  const t = walk.currentNode.textContent.trim();
  if (t.length > 2) nodes.push(t);
}
copy(nodes.join('\n'));

组件使用规则

一致性 · 可访问性 · 动效 · 命名

对比度与可访问性

✓ 推荐

文本与背景对比度 ≥ 4.5:1；交互元素带可聚焦状态（:focus-visible 描边）；图标按钮提供 aria-label。

✕ 避免

用颜色单独传达状态（需配合文字/图标）；移除焦点轮廓；在无障碍树中隐藏可见操作。

间距与对齐

✓ 推荐

所有间距取自 --sp-* 刻度；同组元素保持 8px 基线对齐；卡片内边距统一 16/24px。

✕ 避免

使用任意像素间距导致节奏断裂；同一列表项左右内边距不一致。

动效

✓ 推荐

过渡时长使用 --t-fast/--t-base（120/200ms）；尊重 prefers-reduced-motion；微交互仅用于反馈。

✕ 避免

超过 400ms 的非必要动画；页面级闪烁；阻断操作的长时间加载无进度提示。

命名约定

✓ 推荐

基础组件用通用名（.btn/.field/.badge）；业务组件加 b- 前缀（.b-engine）；修饰类用 -primary/-sm/-lg。

✕ 避免

语义化含义冲突的类名（如 .blue-btn）；按页面位置命名（如 .top-left-box）。
